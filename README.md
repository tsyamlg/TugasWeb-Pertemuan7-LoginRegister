# Sistem Login/Register PHP Native
Cara menjalankan (Laragon/XAMPP):
1. Salin folder ini ke `C:\laragon\www\` (Laragon) atau `C:\xampp\htdocs\` (XAMPP).
2. Start Apache, buka `http://localhost/login-register-php/`.
3. Daftar -> data tersimpan di `data/users.json` -> Login -> Dashboard -> Logout.
Butuh PHP 7.4+ (disarankan 8+).
